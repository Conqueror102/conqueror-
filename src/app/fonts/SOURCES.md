# Local font assets

Delius and fredoka-semibold.ttf (a static Fredoka 600 instance for the share image, which cannot read variable fonts) are from the Google Fonts CSS API. Fredoka and JetBrains Mono use the
original variable TrueType files in the official google/fonts repository.
Files are stored locally to keep builds independent of Google Fonts network
access. Each font's SIL Open Font License is included.

- https://fonts.google.com/specimen/Delius
- https://fonts.google.com/specimen/Fredoka
- https://fonts.google.com/specimen/JetBrains+Mono
